# POS-DEC-001: Prüfkriterien und belegte Ergebnisabnahme

| Feld | Festlegung |
| --- | --- |
| ID | POS-DEC-001 |
| Datum / Status | 17.11.2026 / ACCEPTED |
| Entscheider | Product Owner |
| Kontext | Empfehlungen, Umsetzung und tatsächliche Ergebnisprüfung sollen zuverlässiger zusammenwirken. Unterschiedliche simulierte Rollen allein sichern die Qualität nicht. |
| Betrachtete Optionen | Zusätzlichen Beraterkreis als Standard einführen; sämtliche Agenten neu gestalten; vorhandenen gemeinsamen Standard gezielt präzisieren und seine Einbindung prüfen. |
| Entscheidung | Bestehenden Standard um prüfbare Kriterien, sachliche Gegenprüfung, proportionale Autonomie und belegte Ergebnisabnahme ergänzen. Im Project Operating System gemeinsame Repository-Einstiege einbinden. Drei kleine Anwendungsproben und einen ehrlichen Ausgangsvergleich vorbereiten. |
| Autorisierung | Ausdrücklicher Product-Owner-Auftrag vom 17.11.2026 zur selbstständigen Umsetzung des zuvor vorgeschlagenen Maßnahmenpakets, soweit technisch möglich; Rückfragen nur für zwingend vom Nutzer vorzunehmende Schritte. Die Autorisierung umfasst die geprüfte Übernahme dieses abgegrenzten Pakets. |
| Begründung | Bereits vorhandene Entscheidungs- und Qualitätsregeln wirksam anwenden und gezielt ergänzen; vermeidbare Rückfragen und Korrekturschleifen reduzieren. |
| Auswirkungen | Gemeinsamer Kern in AGENTS.md; Repository-Einstiege für Codex, Claude Code und GitHub Copilot; kompakter ChatGPT-Kopiertext; ergänzte Workflow-, Entscheidungs- und Qualitätsregeln; dokumentierte Anwendungsproben. |
| Grenzen | Keine neue PPAO-Produktivfreigabe, keine pauschale Installation oder Aktivierung weiterer Agenten, kein globaler Claude-Rollout und keine Änderung laufender Fachprojekte. PPAO-DEC-001 und bestehende projektbezogene Sperren bleiben gültig. |
| Betroffene Artefakte | AGENTS.md, CLAUDE.md, .github/copilot-instructions.md, README.md sowie die verlinkten Workflow-, Entscheidungs-, Qualitäts- und Übernahmedokumente. |
| Reversibilität | Abgegrenzter versionierter Lieferstand; nachfolgende Änderungen mit eigenem Nachweis. |
| Erfolgssignal | Keine übersehenen Pflichtanforderungen und keine kritischen Regressionen; im praktischen Vergleich weniger notwendige Korrekturen oder Rückfragen bei erhaltener Ergebnisqualität. Ohne Vergleichsdaten keine behauptete Verbesserung. |
| Wiedervorlage | Nach den drei vergleichbaren Praxisfällen; vorher keine weitergehende Agentenumstellung aus dem Vorprüfungsresultat ableiten. |
| Ersetzt / ersetzt durch | Ergänzt den bisherigen POS-Standard. Historische Entscheidungen und PPAO-Fassungen werden nicht überschrieben. |
